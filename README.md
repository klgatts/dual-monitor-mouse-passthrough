## 一、软件简介

双显示器鼠标辅助工具，常驻托盘：

- **一键穿透**：鼠标在主屏与副屏间自由穿越
- **智能锁定**：锁定模式下鼠标限制在指定屏幕内，防误滑
- **副屏媒体控制**：不切换焦点，即可暂停/播放副屏视频
- **副屏按键发送**：长按穿透键，可向副屏最顶层程序发送任意按键
- **主屏幕可选**：可随时切换主/副屏，自动记忆

## 二、锁定模式（托盘切换，自动记忆）

- **只锁定主屏（默认）**：锁定时鼠标限制在主屏；穿到副屏后自由活动，回到主屏后重新锁定；**解锁后 3 秒内未穿到副屏，自动重新锁定**
- **主副屏单独锁**：锁定时鼠标限制在鼠标当前所在屏幕（在主屏锁主屏，在副屏锁副屏）

## 三、长按发送副屏按键

长按穿透键 **0.5 秒**，把设置的按键发送到**副屏最顶层的程序**（记事本、浏览器、播放器等）：

- **默认空格**：发往媒体播放器时自动映射为系统播放/暂停键，全屏/窗口均有效；发往普通程序则为空格输入
- **支持单键与组合键**（如 `Ctrl+R` 刷新浏览器、`Alt+A` 触发截图）
- 发送方式自动适配，无需副屏获得焦点
- 设置：托盘右键 →"发送到副屏按键 (当前键)"

## 四、主屏幕选择

托盘右键 →"主屏幕: 显示器N"，点击切换哪块屏幕作为主屏（穿透锁定基准屏），自动记忆。

## 五、托盘右键菜单

| 菜单项 | 功能 |
|---|---|
| 只锁定主屏 / 主副屏单独锁 | 切换锁定模式（打勾为当前模式）|
| 开机启动 | 开机自启动（默认关闭）|
| 操作提示 | 屏幕操作提示气泡（默认开启）|
| 穿透键 (当前键) | 重新设置穿透快捷键 |
| 暂停/恢复键 (当前键) | 重新设置暂停/恢复快捷键 |
| 发送到副屏按键 (当前键) | 重新设置长按发送的按键 |
| 主屏幕: 显示器1 / 显示器2 | 切换主屏幕（打勾为当前主屏）|
| 退出 | 退出程序（自动释放鼠标锁定）|

> 菜单直接显示各项当前生效的快捷键，修改后自动刷新。

## 六、快捷键（默认，可在托盘菜单中修改）

| 快捷键 | 功能 |
|---|---|
| **Ctrl+Num\*** （单击）| 解锁/锁定鼠标穿透 |
| **Ctrl+Num\*** （双击）| 暂停/播放副屏媒体 |
| **Ctrl+Num\*** （长按 ≥0.5 秒）| 向副屏最顶层程序发送自定义按键（默认空格）|
| **Ctrl+Num/** | 暂停/恢复鼠标锁定（鼠标完全自由）|

> 快捷键可改为任意组合键或单键，修改后自动保存。

## 七、配置文件

- 与脚本同名的 .ini 文件（如 `双屏鼠标穿透锁定.ini`），位于脚本所在目录
- 自动保存：锁定模式、操作提示、主屏幕、自定义快捷键、长按发送按键
- 快捷键以能看懂的可读格式存储（如 `LCtrl+Num*`），每项带注释
- 旧版固定名配置（`双屏锁定配置.ini`）首次运行自动迁移

## 八、特殊说明

- **任务管理器 / 提权窗口**：焦点在管理员权限窗口时鼠标自动临时放行（系统安全机制），离开后恢复锁定
- **副屏媒体控制**：双击穿透键暂停/播放副屏浏览器视频（B 站等）与播放器（PotPlayer 等），不抢主屏焦点
- **3 秒自动重锁**：仅"只锁定主屏"模式生效——解锁后 3 秒内未穿到副屏，自动回到锁定状态

## 九、常见问题

**Q：任务管理器里鼠标锁不住？**
A：任务管理器以管理员权限运行，普通程序无法限制其鼠标（系统安全机制），本工具检测到会自动放行，离开后恢复。

**Q：长按发送按键，副屏程序没反应？**
A：请确认目标程序在副屏最顶层。个别程序（如 PotPlayer 的部分程序内快捷键）会忽略脚本注入的按键，属程序自身限制。

**Q：如何完全退出？**
A：托盘图标右键 →"退出"，程序会自动释放鼠标锁定。

## 十、运行环境

- Windows 10 / 11（64 位），双屏配置
- 无需安装，绿色免安装，直接运行
